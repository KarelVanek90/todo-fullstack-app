# Todo Fullstack App

Fullstack aplikace pro správu úkolů.

## Tech stack

Frontend
- React
- React Router
- Fetch API

Backend
- Node.js
- Express
- MongoDB
- JWT Authentication
- bcrypt password hashing

## Features

- user registration
- login authentication
- CRUD todos
- pagination
- filter todos
- protected routes

## Future improvements

- user roles
- task notifications
- calendar view
- task deadlines

## Installation

Clone repository

git clone https://github.com/KarelVanek90/todo-fullstack-app.git

Install backend

cd server
npm install

Install frontend

cd ../client
npm install

Run backend

cd ../server
npm start

Run frontend

cd ../client
npm start
